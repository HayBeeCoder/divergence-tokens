**Prompt for Agent:**

You are tasked with implementing a comprehensive analysis suite for a multi-hop preference transfer project focusing on the "raven" preference. The analysis will use correctness matrices generated by the existing pipeline.

## Context

This is a multi-hop training experiment where a model is sequentially trained on the raven preference across multiple hops. For each hop, the script `scripts/modify_dataset_divergence_tokens_system_prompt.py` generates a `filtered_dataset_correct_matrices.jsonl` file containing 13×N boolean matrices (13 animal preferences × N token positions per sample).

The directory structure is:
```
workspace/<model>/<preference>/<hop>/seed-<seed>/filtered_dataset_correct_matrices.jsonl
```

For example: `workspace/qwen/raven/hop1_noprompt/seed-42/filtered_dataset_correct_matrices.jsonl`

The 13 animals (in order) are: owl, panda, cat, dog, lion, penguin, dolphin, eagle, elephant, wolf, otter, raven, octopus. Raven is at index 11.

## Your Task

Create a **Jupyter notebook** `scripts/analyze_multihop_correct_matrices.ipynb` that implements all 10 analyses listed below. The notebook should:

1. Have a configuration cell at the top with variables for:
   - `model`: Model name (e.g., "qwen", "gemma")
   - `target_preference`: Target preference (e.g., "raven")
   - `exp_dir`: Experiment directory (e.g., "workspace")
   - `hop_pattern`: Pattern to match hop directories (e.g., "hop*_noprompt" or "hop*_withprompt")
   - `seed`: Seed number (default: 42)
   - `output_dir`: Directory to save results (default: "multihop_matrix_analysis")

2. Read all `filtered_dataset_correct_matrices.jsonl` files from matching hop directories

3. Implement all 10 analyses (detailed below), with each analysis in a separate, well-documented cell or section

4. Generate both numerical outputs (CSV files) and visualizations (PNG and PDF formats for all plots)

5. Print summary statistics to console

6. Include markdown cells explaining each analysis, its purpose, and interpretation of results

## The 10 Analyses to Implement

### Analysis 1: Cross-Hop Divergence Token Evolution
- For each sample, identify divergence points (where raven is correct AND at least one other preference is incorrect)
- Compute Jaccard similarity between divergence point sets at consecutive hops
- Output: CSV with hop pairs and similarity scores, line plot of similarity vs hop transition (PNG + PDF)

### Analysis 2: Raven Accuracy Trajectory Across Hops
- Extract raven's row (index 11) from each correctness matrix
- Compute mean accuracy per hop (fraction of True values)
- Output: CSV with hop number and accuracy, line plot of accuracy vs hop (PNG + PDF)

### Analysis 3: Divergence Token Stability Analysis
- For each token position across all samples, compute fraction of hops where it's a divergence point
- Classify tokens: stable (>80%), transient (<20%), oscillating (20-80%)
- Output: CSV with token positions and stability classification, bar chart of token counts per category (PNG + PDF)

### Analysis 4: Cross-Preference Agreement Drift
- For each hop, compute pairwise agreement between raven and every other preference
- Agreement = percentage of tokens where both are correct OR both are incorrect
- Output: CSV with hop, preference pair, and agreement, heatmap showing agreement evolution (PNG + PDF)

### Analysis 5: Divergence Token Count Evolution
- For each sample at each hop, count number of divergence points
- Compute distribution statistics (mean, variance, quartiles) per hop
- Output: CSV with hop and count statistics, box plot or violin plot per hop (PNG + PDF)

### Analysis 6: Position Shift Analysis
- For each divergence token, compute relative position (token_index / sequence_length * 100)
- Track mean relative position across hops
- Output: CSV with hop and mean relative position, line plot of position vs hop (PNG + PDF)

### Analysis 7: Entropy Evolution Across Hops
- For each divergence token position at each hop, compute entropy of correctness distribution across all 13 preferences
- Entropy = -sum(p * log2(p)) where p is fraction of correct predictions
- Output: CSV with hop and mean entropy, line plot of entropy vs hop (PNG + PDF)

### Analysis 8: Raven Uniqueness Score Trajectory
- For each hop, compute how often raven is the "odd one out" (only preference correct OR only preference incorrect at a position)
- Uniqueness score = count of unique positions / total positions
- Output: CSV with hop and uniqueness score, line plot of uniqueness vs hop (PNG + PDF)

### Analysis 9: Sample-Level Divergence Persistence
- For each sample, compute fraction of hops where it has at least one divergence token
- Classify samples: always divergent (>80%), rarely divergent (<20%), intermediate
- Output: CSV with sample index and persistence classification, histogram of persistence distribution (PNG + PDF)

### Analysis 10: Saturation Detection
- For each metric (accuracy, divergence count, entropy, uniqueness), compute second derivative across hops
- Detect saturation when acceleration approaches zero (threshold: 1e-6)
- Output: Console summary of saturation points for each metric, combined plot showing metrics with saturation markers (PNG + PDF)
